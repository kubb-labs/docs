# OpenAPI and Scalar

Kubb generates code from an OpenAPI document. These links cover the format and a tool to explore it.

## OpenAPI

- [OpenAPI Initiative](https://www.openapis.org/) hosts the specification and its community.
- [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) defines the document format Kubb reads.
- [OpenAPI learning resources](https://learn.openapis.org/) explain the format with guides and examples.

## Scalar

- [Scalar](https://scalar.com/) renders an interactive API reference from an OpenAPI document.
- [Scalar documentation](https://guides.scalar.com/scalar/introduction) covers setup and configuration.
- [Scalar on GitHub](https://github.com/scalar/scalar) holds the source code.

## See also

- [Configuration](/docs/5.x/reference/configuration) sets the `input` Kubb reads.
